Cloud Provider Guides

📄️Fly

Zealot support use App Configuration (fly.toml) to deploy on fly.io.

📄️Railway

Zealot support use Dockfile to deploy on Railway.

📄️Render

Zealot support a render blueprint named render.yaml to deploy on render.com.
