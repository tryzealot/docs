隐私政策

欢迎使用 Zealot！

我们非常重视您的隐私。本隐私政策说明了您在使用 Zealot 时，我们如何收集、使用、披露和保护您的信息。Zealot 提供开源版和付费版（自部署），不同版本的数据收集方式有所不同。

1. 我们收集的信息​

开源版本​

  • 匿名错误上报： Zealot 使用 Sentry 进行匿名错误上报，具体内容可能包含部分个人可识别信息（PII），具体取决于错误内容。您可以在配置中关闭 Sentry 上报。详情请参见 Sentry 官方文档。
  • 网站统计： Zealot 文档和演示站点使用 Microsoft Clarity 进行网站统计，数据收集遵循 Microsoft Clarity 隐私政策。您的自部署 Zealot 实例不会收集任何网站统计数据。

付费版本（自部署）​

付费版本为自部署服务，我们不会从您的实例收集任何分析或使用数据。唯一可能收集的数据包括：

  • 匿名错误上报： Zealot 使用 Sentry 进行匿名错误上报，具体内容可能包含部分个人可识别信息（PII），具体取决于错误内容。您可以在配置中关闭 Sentry 上报。详情请参见 Sentry 官方文档。
  • 购买/支持所需的个人信息： 若您购买付费授权，我们仅会收集必要的个人信息（如姓名、邮箱、账单信息），仅用于账单和客户支持。该信息不会与您的自部署 Zealot 实例数据关联。

统计集成（自部署）​

Zealot 支持 Umami 和 Google Analytics 的可选统计集成。如果您启用这些统计服务，数据仅会发送到您配置的统计服务（如您自有的 Umami 实例或您的 Google Analytics 账号）。Zealot 本身不会默认收集或传输任何统计数据。请参考相关统计服务的隐私政策，了解其数据收集和使用方式。

2. 我们如何使用您的信息​

开源版本​

  • 匿名错误数据仅用于提升 Zealot 的稳定性和可靠性。不会出售或共享您的个人数据。
  • 文档和演示站点的统计数据仅用于改进内容和用户体验。

付费版本（自部署）​

  • 匿名错误数据仅用于提升 Zealot 的稳定性和可靠性。不会从您的自部署实例收集任何分析或使用数据。
  • 购买或支持时提供的个人信息仅用于相关目的，不与您的 Zealot 实例数据关联。

3. 信息共享​

我们不会出售或出租您的个人信息。仅在以下情况下可能共享您的信息：

  • 获得您的同意
  • 遵守法律义务
  • 保护 Zealot、用户或他人的权利和安全
  • 与协助 Zealot 运营的服务提供商（在保密协议下）

开源版本仅在启用时将匿名错误数据发送至 Sentry。文档和演示站点的统计数据由 Microsoft Clarity 管理。

4. 数据安全​

我们采取合理措施保护您的信息不被未经授权访问、披露、篡改或破坏。但请注意，任何互联网传输或电子存储方式都无法保证 100% 安全。开源用户可随时关闭 Sentry 上报。

5. 您的权利​

您有权访问、更正或删除您的个人信息（付费版本）。您也可以反对或限制我们对您数据的某些处理。如需行使这些权利，请联系我们。

6. 政策变更​

我们可能会不时更新本隐私政策。如有重大变更，我们将在 Zealot 上发布新政策。您在政策变更后继续使用 Zealot，即表示接受新政策。

7. 联系我们​

如对本隐私政策有任何疑问或担忧，请通过 contact@ews.im 联系 Zealot 团队。
